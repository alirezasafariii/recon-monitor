# Analysis Engine 6.31 — Fresh Blind v6 Validation Protocol

Analysis 6.31 freezes the completed Analysis 6.30 production logic before any new source discovery or scoring.

The v6 evaluation is pre-registered as 276 cases: 144 single-family cases, 72 two-family interference cases, and 60 three-family interference cases. The source firewall requires 36 fresh roots and 36 fresh projects with zero overlap against prior raw v1-v5 exposure, the Analysis 6.30 calibration set, prior discovery exposure, and detector grounding references.

No production detector, admission, ranking, reasoning, candidate, or orchestration rule may change before the first v6 score. Source selection and materialization must remain unscored. The first v6 evaluation is single-consumption: regardless of pass or fail, its result becomes immutable and any remediation must use a separate calibration set.

Pre-registered goals are intentionally stricter than the historical raw gates, especially for routing accuracy, admission precision/recall, and multi-family exact-set behavior. This phase is validation only; it does not change alert lifecycle behavior or perform active network validation.
