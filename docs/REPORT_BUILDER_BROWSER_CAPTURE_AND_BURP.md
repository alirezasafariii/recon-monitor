# Report Builder, Browser Capture and Burp Round-Trip

Report Builder links claims to persisted Evidence Records and redacted observations. `raw_reference`, credential material and sensitive response bodies are excluded. Unconfirmed cases cannot be phrased as confirmed vulnerabilities.

Browser Capture is metadata-only and scope-filtered. Burp Round-Trip carries evidence gaps, next analyst actions and authorized context labels, but excludes raw credentials/cookies/bodies. Returned analyst observations update the case workflow without automatic confirmation.
