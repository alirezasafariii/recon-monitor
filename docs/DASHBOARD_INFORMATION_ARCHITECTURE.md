# Dashboard Information Architecture

The version 5.0 dashboard is case-first and decision-centered.

## Level 1 — decisions

The Command Center shows, in order:

1. Cases ready for authorized validation
2. Cases blocked by missing evidence
3. New or actively reviewed cases
4. Engine or operational attention
5. Priority case queue
6. Security stories

## Level 2 — work context

Case pages combine decision, evidence, timeline, validation context, and report readiness. Analysts do not need to move between unrelated candidate, alert, note, and report pages.

## Level 3 — technical drill-down

Assets, endpoints, JavaScript, HTTP/TLS, raw alerts, semantic data, behavioral records, and specialist engine pages remain available under Explore and Advanced tools.

## Fallback visibility

High-risk alerts that have not yet been promoted to a case remain visible in an expandable fallback section. Technical inventory appears under Coverage Snapshot instead of competing with urgent decisions.
